# Карточка состояния (шаблон)

Агент создаёт `state/state-card.md` по этому шаблону и обновляет после каждого значимого шага. Машинная часть — `state/stages.tsv`; карточка её читаемое представление.

**Не записывать:** пароли, приватные ключи, токены, публичный IP или имя хоста, имена пользователей, абсолютные пути, адреса почты.
Для сервера использовать слова «сервер», «обычный пользователь», «рабочая папка».

```
Версия комплекта:        <из VERSION>
Дата обновления (UTC):   <ГГГГ-ММ-ДД>
ОС ноутбука:             <windows | macos>   [L]
Режим VPN:               <on | off | unknown>   [U]
Окно сейчас:             <локальное | удалённое>
Провайдер / способ оплаты / план на недоступность панели:  <слова человека>   [U]
Режим разрешений:        Claude <manual|other|unknown>   Codex <default|other|unknown>   [U]
Интервью:                <нет | готово, дата, идентификатор>
Карта (state/map.md):    <нет | готова, дата, идентификатор>
Выбор по этапу 8:        <8A | 8B | не выбран>
```
