# Этап 0. Предстартовый список

**Место:** `AGENT` показывает список, `HUMAN` отвечает. Источник требований: уроки воркшопов (аккаунты, оплата и повторы выяснялись во время встреч).

## Что нужно до этапа 3

| Группа | Что нужно | Кто |
|---|---|---|
| Аккаунты | у провайдера VPS; Claude и/или Codex (авторизация каждого отдельно); ChatGPT, если используется чат-проводник | человек |
| Доступы | рабочий ноутбук с правом установки VS Code; VPN, который остаётся включённым; второе устройство (телефон) для панели провайдера | человек |
| Расходы | аренда сервера (срок), подписки на движки, способ оплаты зарубежного сервиса (карта, виртуальная карта) | человек решает и платит |
| Действия человека | регистрация и оплата; первый вход по паролю; подтверждение отпечатка хоста; смена пароля, если он раскрыт; выбор между 8A и 8B | человек |
| Автоматизируется | всё остальное в пределах доступных инструментов | агент |

## Как вести
1. Показать таблицу и записать ответы в `state/state-card.md` (поля «Провайдер / способ оплаты / план на недоступность панели»). Ответ «не знаю» допустим: запиши `unknown` и иди дальше; остановка нужна только перед платным шагом без ответа.
2. Назвать ожидаемые расходы словами; оплату выполняет человек.
3. Напомнить: VPN на рабочем ноутбуке остаётся включённым; для панели провайдера — телефон или другое устройство.
4. Отметить ожидания по этапам с PASS, а не «за встречу»: комплект не обещает результат за заданное время.

**PASS (этап 0 не нумеруется в `stages.tsv`):** в карточке отмечены аккаунты, доступность способа оплаты, ожидаемые расходы. До этапа 3 без отметок не переходить.
