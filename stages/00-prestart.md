# Этап 0. Предстартовый список и выбор входа

**Место:** `AGENT` показывает список, `HUMAN` отвечает. Источник требований: уроки воркшопов (аккаунты, оплата и повторы выяснялись во время встреч).

## Два входа, одно состояние
- **Начать с GPT-проводником** — основной рекомендуемый вход для новичков: проводник объясняет, что происходит, и формулирует следующий шаг; технические действия и проверки выполняет нейрокоманда. Промпт — `ENTRY.md`, раздел А. Ответ записывается `entry_mode=gpt_guide`.
- **Начать сразу в VS Code** — второй вариант: стартовый промпт из `ENTRY.md`, раздел Б, отправляется прямо в панель Claude или Codex. Ответ: `entry_mode=vscode_direct`.

Это один комплект и одно состояние: переход между входами в любой момент не меняет `state/` и не начинает маршрут заново. Источник истины — файлы состояния и проверенные результаты, а не чат.

## Что нужно до этапа 3

| Группа | Что нужно | Кто |
|---|---|---|
| Аккаунты | у провайдера VPS (новый или уже существующий — ответ `account_state`); Claude и/или Codex (авторизация каждого отдельно); ChatGPT, если выбран вход с проводником | человек |
| Доступы | рабочий ноутбук с правом установки VS Code; VPN, который остаётся включённым; второе устройство (телефон) для панели провайдера | человек |
| Оплата | способ оплаты зарубежного сервиса (карта, виртуальная карта) | человек платит |
| Сервер | есть ли он уже (`server_state`: `none`, `existing_active`, `replaced`, `unknown`) | человек отвечает |
| Движки | `engine_mode`: `claude_only`, `codex_only`, `both` или `undecided`; одного достаточно | человек выбирает |
| Действия человека | регистрация и оплата; первый вход по паролю; подтверждение отпечатка хоста; смена пароля, если он раскрыт; выбор между 8A и 8B | человек |
| Автоматизируется | всё остальное в пределах доступных инструментов | агент |

## Как вести
1. Показать таблицу и записать ответы в `state/state-card.md` (поля «Провайдер / способ оплаты / план на недоступность панели») и через `-Answer` (`entry_mode`, `server_state`, `engine_mode`, `account_state`). Ответ «не знаю» допустим: запиши `unknown` и иди дальше; остановка нужна только перед платным шагом без ответа.
2. Оплату выполняет человек.
3. Напомнить: VPN на рабочем ноутбуке остаётся включённым и не отключается; для панели провайдера — телефон или другое устройство.
4. Проверить режим разрешений **до** установки и до операций с кодом: Claude — Manual, Codex — штатные подтверждения. Если режим Auto блокирует внешний код, объяснить точный переключатель и запросить штатное разовое разрешение; широкие правила не предлагать.
5. Отметить ожидания по этапам с PASS, а не «за встречу»: комплект не обещает результат за заданное время.

**PASS (этап 0 не нумеруется в `stages.tsv`):** в карточке отмечены вход, аккаунты, состояние сервера, выбор движков, доступность способа оплаты. До этапа 3 без отметок не переходить.
