# Этап 7. Claude и/или Codex на хосте, авторизация

**Вход:** этап 5 PASS (удалённое окно работает) и выбранный `engine_mode` (`claude_only`, `codex_only`, `both`). Один движок — полноценный поддержанный путь; второй добавляется по желанию.

## Официальные расширения (реестр, не поиск по случайным сборкам)
| Движок | ID расширения | Где ставится |
|---|---|---|
| Claude | `anthropic.claude-code` | на SSH-хост (удалённое окно) |
| Codex | `openai.chatgpt` | на SSH-хост (удалённое окно) |

Локальная установка не засчитывается как удалённая: диагностика видит только локальные расширения, а расширения на SSH-хосте проверяются в интерфейсе удалённого окна и минимальной командой. Платформу и архитектуру сервера (`uname -m`) назови до поиска пакета; если установка из Marketplace не удалась, делается **один адресный разбор** по тексту ошибки (официальный пакет, архитектура, версия VS Code); бесконечный поиск сборок и неофициальные архивы не используются. Пакетный запасной путь (установка через CLI движка) — только при конкретной ошибке и с подтверждением.

| Место | Действие |
|---|---|
| `AGENT` | сначала попробовать доступный ему путь установки на SSH-хост; зафиксировать результат; проверить, что расширение стоит **на SSH-хосте**; выполнить каждым выбранным движком минимальную команду на сервере |
| `HUMAN` (интерфейс удалённого окна VS Code) | только если у агента нет инструмента для клика: одна кнопка «Install in SSH: …» в указанном окне; авторизация **отдельно для каждого** движка; пароли, токены и коды вводит только человек |

## Правила
- CLI — дополнительный вариант, не обязательный этап.
- Сбой авторизации: сначала повторить тот же вызов (расширение или CLI), затем сменить способ входа. Сеть и VPN не менять.
- Режим разрешений: Claude — Manual; Codex — штатные подтверждения. Bypass и широкие постоянные разрешения не включать. Отказ — `BLOCKED_BY_LOCAL_PERMISSION`, обход не искать.
- Проблема песочницы (`bwrap`) в референсе описана владельцем без деталей `[U]`; если движок сообщает о ней, зафиксируй текст ошибки без секретов и не пытайся обходить песочницу как штатное решение.

**PASS:** каждый **выбранный** движок выполняет команду на VPS (в выводе виден хост, а не ноутбук). Один движок при `claude_only` или `codex_only` достаточен; при `both` второй записывается отдельным фактом, но решение работать с одним человек может принять позже, этап при этом не блокируется. `-Fact ENGINE_READY=PASS -Source engines-run -Evidence LU`, затем `-Accept 7 -Source engines-run -Evidence LU`.

**Ошибка:** ветка «Движки» (расширение не авторизовано; команда на VPS не выполняется): один следующий шаг, SSH и сервер не считать сломанными.

Статус референса: Claude и Codex выполняют команды на VPS `[U]`.
