# Происхождение исходников демо

Демо в комплекте — **версия 2**, сделанная на основе версии 1, которую владелец получил с эталонного сервера. Эталонное приложение на сервере этой работой **не менялось**: версия 2 существует только в комплекте.

## Исходная версия 1 (происхождение)
Файлы версии 1 получены **read-only** с эталонного сервера (каталог проекта `workshop-demo`, пользователь с ключом, VPN включён) 2026-10-05. Приложение, его процесс и сервер не менялись. Брались только три исходника; серверные `STATUS`, `handoffs`, QA-отчёт и README в комплект не входили. SHA-256 на сервере совпали с хешами полученных файлов (сверено при получении и повторно при сборке выпуска `0.1.2-preview`).

## Версия 2 (в этом комплекте)
Версия 2 сохраняет всё поведение версии 1: список задач (добавить, отметить выполненной, удалить, удалить все выполненные), тот же ключ `localStorage` `workshop-demo.tasks.v1` (задачи, созданные в версии 1, остаются доступны). Добавлено (2026-10-08):
- явная практическая проверка («Начать проверку», «Повторить проверку», «Отменить проверку»): приложение само отслеживает сценарий из четырёх шагов — две новые задачи, одна отмечена, обновление страницы с подтверждением сохранения, удаление выполненной при оставленной второй; прежние задачи за прогресс не засчитываются и проверкой не удаляются (на время проверки кнопка «Удалить выполненные» отключена);
- экран завершения только после пройденного сценария, с двумя действиями и готовым сообщением для копирования («Продолжить с GPT-проводником», «Продолжить с нейрокомандой в VS Code»); автоматического переключения нет;
- одно короткое конфетти при завершении (без внешних библиотек, с учётом `prefers-reduced-motion`, кнопки не блокирует).

Исходники созданы в проекте владельца при участии ИИ-агентов (Claude, Codex) по заданиям владельца и распространяются на условиях Apache-2.0 в пределах прав владельца на них; оригинальность и отсутствие чужих прав не гарантируются (раздел 7 лицензии).

Сборка комплекта проверяет, что файлы в `demo/workshop-demo/` совпадают с хешами версии 2. Любое изменение приложения означает новую версию: хеши записываются в этот файл отдельным решением, происхождение (версия 1 и её хеши) сохраняется.
