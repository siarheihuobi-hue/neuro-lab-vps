# demo/ — демонстрационное приложение для этапа 11

В комплекте лежит готовое приложение **«Моя нейрокоманда»**: страница со списком задач (добавить, отметить выполненной, удалить, удалить все выполненные). Это обычные HTML, CSS и JavaScript без внешних библиотек, исходники — в `demo/workshop-demo/` (`index.html`, `style.css`, `app.js`). Содержимое приложения комплект не меняет; происхождение и хеши файлов — `SOURCE-HASHES.md`.

## Три факта, которые нельзя путать
- **Данные — `localStorage` браузера** (ключ `workshop-demo.tasks.v1`). Они лежат в браузере вашего ноутбука, а не на сервере. Сохранение после F5 доказывает хранение в браузере, а не на VPS. Если открыть приложение в другом браузере или в приватном окне, задач там не будет.
- **Сервер приложения слушает только loopback** (`127.0.0.1`). Снаружи сервер недоступен; публичные порты открывать не нужно и нельзя, правила файрвола для демо не меняются.
- **Открытие — через вкладку Ports в VS Code**: проброс порта с сервера на ноутбук.

## Запуск (место: `AGENT` в удалённом терминале или `HUMAN-REMOTE-TERMINAL`)
Нужен только `python3`; проверьте, что он есть: `python3 --version`. Установка пакетов не требуется; если `python3` нет, это отдельное подтверждение человека.
```
cd <папка комплекта на сервере>/demo/workshop-demo
python3 -m http.server 56891 --bind 127.0.0.1
```
Порт `56891` взят из эталонного прогона; если он занят (`ss -ltn`), возьмите любой свободный. Адрес обязательно `127.0.0.1`: без `--bind` сервер слушает все интерфейсы.

## Открытие (место: `HUMAN`, интерфейс VS Code в удалённом окне)
Панель **Ports** → **Forward a Port** → номер порта → откройте выданный локальный адрес в браузере.

## Остановка
`Ctrl+C` в терминале, где запущен сервер. Если запущен в фоне: `pkill -f "http.server 56891"` (подставьте свой порт). Работа фонового процесса после переподключения комплектом **не обещается**; после reconnect его проверяют и при необходимости запускают заново (этап 12).

## Что проверяет этап
Проверки — `CHECKS.md`. Агент проверяет loopback и отсутствие правил файрвола; человек проходит сценарии в браузере.

## Известные ограничения демо
Необязательные замечания по демо-приложению (QA-отчёт эталонного прогона, в комплект не входит) не исправлялись: демо — учебный пример, а не продукт. В приложении нет серверной части и входа, оно не предназначено для хранения важных данных.
