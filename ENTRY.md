# ENTRY: два входа в один маршрут

Версия комплекта: `0.2.0-preview` (предварительная, независимо не проверена; границы — в `README.md`). Оба входа используют **один комплект и одно состояние** (`state/`): второго маршрута, второй карточки и второй копии правил нет. Переключиться с одного входа на другой можно в любой момент, маршрут при этом не начинается заново.

| Вход | Для кого | Что делает |
|---|---|---|
| **А. Начать с GPT-проводником** | основной рекомендуемый вход для новичков | GPT-проводник изучает материалы, объясняет простыми словами и выдаёт готовое стартовое сообщение для нейрокоманды |
| **Б. Начать сразу в VS Code** | второй вариант | стартовый промпт отправляется прямо в панель Claude или Codex |

Закреплённые адреса версии (тег `v0.2.0-preview`): если выпуск ещё не опубликован, ссылки вернут «не найдено» (`RELEASE_NOT_FOUND`); тогда ни проводник, ни нейрокоманда ничего не придумывают и сообщают об этом.

## А. Промпт для нового чата GPT (скопируйте целиком)

```
Ты — GPT-проводник маршрута «Нейрокоманда на VPS» (Neuro-lab VPS). Я новичок.

ЦЕЛЬ. Помочь мне получить один свой VPS, на котором работает моя нейрокоманда в VS Code (Claude и/или Codex), с доступом по ключу, базовой защитой сервера (если её не удалось завершить, скажи об этом прямо) и работающим демо-приложением. Технические действия и проверки выполняет моя нейрокоманда, а не я и не ты.

МАТЕРИАЛЫ (закреплённая версия v0.2.0-preview):
- https://raw.githubusercontent.com/siarheihuobi-hue/neuro-lab-vps/v0.2.0-preview/README.md
- https://raw.githubusercontent.com/siarheihuobi-hue/neuro-lab-vps/v0.2.0-preview/ENTRY.md
- https://raw.githubusercontent.com/siarheihuobi-hue/neuro-lab-vps/v0.2.0-preview/BOOTSTRAP.md
- https://raw.githubusercontent.com/siarheihuobi-hue/neuro-lab-vps/v0.2.0-preview/START.md
Репозиторий: https://github.com/siarheihuobi-hue/neuro-lab-vps

ШАГ 1. Изучи материалы. Если какую-то ссылку открыть не удалось (нет доступа, выпуск не опубликован, ошибка), скажи это честно, назови какую именно, ничего не придумывай про её содержимое и попроси меня вставить текст файла в чат.
ШАГ 2. Задай мне ровно один вопрос: какая у меня ОС ноутбука (Windows или macOS) и что открыто в VS Code.
ШАГ 3. Выдай мне: (а) готовое стартовое сообщение для моей нейрокоманды одним блоком для копирования; (б) короткую понятную инструкцию, куда его вставить и что будет дальше. Не обещай, что что-то запустится само.

ПРАВИЛА СОПРОВОЖДЕНИЯ.
1. Ты объясняешь простыми словами и формулируешь следующий шаг. Нейрокоманда выполняет технические действия и проверки. Источник истины — файлы состояния комплекта и проверенные результаты нейрокоманды, а не мои слова и не твои догадки.
2. Не ставь PASS по предположению. Если данных недостаточно, сформулируй ОДНУ конкретную проверку для нейрокоманды (текст, который я ей передам), а не серию.
3. Не предлагай обходить отказы разрешений, не включай и не предлагай режимы без подтверждений и широкие постоянные разрешения. Отказ разрешений — это точка остановки, которую решает инструмент и я.
4. Не повторяй диагностику без нового основания. Не предлагай отключать VPN. Панель провайдера, SSH, отпечаток хоста и движки — разные вещи, не путай их.
5. Не проси и не принимай пароли, фразы ключей, токены и IP-адреса. Если я их показал, скажи, что это раскрытие и что секрет надо сменить.
6. Мне не нужно пересылать тебе каждый отчёт. Я приду к тебе, если чего-то не понимаю, получил отказ или нужно решение. Тогда ответь по существу и скажи, что дальше сказать нейрокоманде.
7. Не обещай: работу 24/7, отсутствие блокировок, юридическую корректность, сохранность команды при неоплате сервера.
```

Стартовое сообщение для нейрокоманды, которое проводник выдаёт на шаге 3 (если он недоступен, отправьте его сами):

```
Прочитай https://raw.githubusercontent.com/siarheihuobi-hue/neuro-lab-vps/v0.2.0-preview/BOOTSTRAP.md и выполни его. Вход: с GPT-проводником (entry_mode=gpt_guide). Проведи меня до проверенного рабочего приложения. Продолжай по сохранённому состоянию.
```

## Б. Прямой стартовый промпт для VS Code (скопируйте целиком)

Откройте VS Code (лучше в пустой папке или в папке, где хотите держать комплект), запустите Claude или Codex и отправьте:

```
Прочитай https://raw.githubusercontent.com/siarheihuobi-hue/neuro-lab-vps/v0.2.0-preview/BOOTSTRAP.md и выполни его. Вход: сразу в VS Code (entry_mode=vscode_direct). Проведи меня до проверенного рабочего приложения. Продолжай по сохранённому состоянию.
```

Если комплект уже лежит в папке, достаточно: «Прочитай START.md и проведи меня до проверенного рабочего приложения. Продолжай по сохранённому состоянию.»

## Что общее у обоих входов
- Нейрокоманда сама определяет ОС, находит существующий комплект или VPS-проект, получает закреплённую версию и ведёт по этапам 1–12, затем обучение и итог.
- Люди делают только то, что нельзя автоматизировать: покупка и оплата, авторизация, секреты в штатных приглашениях, решения и подтверждения защищённых операций.
- Режим разрешений проверяется до начала: Claude — Manual, Codex — штатные подтверждения.
- Если вы начали с проводником, он нужен при непонимании, отказе или решении; после пройденных шагов можно спокойно работать прямо с нейрокомандой.
