# preflight-vps (read-only проверка сервера)

Файл `vps-preflight` — копия ранней внутренней версии preflight 1.2.0 с изменениями комплекта: публичный IP не печатается и не пишется в JSON-отчёт (`public_ip: hidden`).

Запуск на сервере (агент, место `AGENT`, обычный пользователь или root):
```
bash vps-preflight foreign --name=<метка> --provider=<провайдер> --country=<страна> --json=./vps-preflight-report.json
```
Что делает: только читает (система, сеть, SSH, файрвол, порты). Ничего не меняет, секретов не печатает. Недоступное в данных честно получает `UNKNOWN`. `PRE-BOOTSTRAP: READY` означает «можно продолжать настройку» (отсутствие файрвола и вход по паролю на новом сервере не блокеры); `SECURITY-BASELINE READY` — достигнут базовый уровень безопасности (key-only SSH, root закрыт, файрвол активен).

**Порог памяти.** Номинальные 4 GB в гостевой ОС выглядят как около 3,8 GB. В скрипте допуск выражен как `NOMINAL_TOLERANCE_PCT=90` (то есть пол около 3,6 GB для номинала 4 GB, значение `MemTotal` в МБ). Допуск взят из исходного скрипта и владельцем отдельно не утверждён `[?]`. Значение в допуске даёт предупреждение, а не отказ; повышение тарифа из-за 3,8 GB не навязывается.

**Границы:** скрипт не может доказать выделенный/статический IP (всегда `UNKNOWN`), не видит файрвол провайдера, не проверяет авторизацию движков. Сетевые запросы идут **с вашего сервера** к сторонним сервисам, и они видят адрес сервера: определение внешнего адреса (`ifconfig.me`, `icanhazip.com`, `ipinfo.io`), DNS и HTTPS-доступность нейтрального узла (`cloudflare.com`) и (для роли foreign) доступность `api.anthropic.com`, `claude.ai`, `api.openai.com`, `auth.openai.com` без входа. Это исключение из правила «в комплекте только адреса GitHub и документации»: адреса не пишутся в отчёт, а скрипт запускает человек или агент на сервере по его подтверждению. Происхождение скрипта: ранняя внутренняя версия 1.2.0 из материалов владельца репозитория; он распространяется на условиях Apache-2.0 в пределах прав владельца на него. Имя пользователя в отчёт не пишется. Отчёт JSON по умолчанию создаётся в текущей папке: задайте `--json=state/preflight.json` (папка `state/` не попадает в Git).
